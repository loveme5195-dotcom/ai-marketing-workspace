取得自己的金鑰 ↗

只接受 localhost、127.0.0.1 或 [::1]。請在執行 Ollama 的同一台電腦操作；手機的 localhost 是手機本身。連線失敗不會改送雲端。

線上版連接 Ollama 時，請允許瀏覽器「本機網路存取」。第一次讀取模型或測試時若出現詢問，確認是本工作台後選擇「允許」。

沒有跳出詢問，或曾經按過封鎖？
  1. 先在電腦執行「檢查並啟動Ollama.bat」，確認服務與 CORS 檢查通過；一般預設位址為 http://127.0.0.1:11434。
  2. Chrome／Edge：點網址列左側的網站資訊圖示，進入「網站設定／此網站的權限」，找到「本機網路存取」（Local network access；名稱依版本而異），允許目前工作台網站。若找不到，請參考下方官方說明。
  3. 回到工作台重新整理，再選擇 Ollama、讀取模型並執行「測試連線與 JSON 格式」。重新整理後需重新設定 AI，專案仍保留於原瀏覽器。
  4. 仍無法連線時，改用電腦版 Chrome／Edge；若選項由學校或公司管理，請洽管理員確認權限。

只調整本工作台的網站權限；不需要清除瀏覽器資料。授予瀏覽器權限與 Ollama 允許網站來源（CORS）是兩項不同設定。
