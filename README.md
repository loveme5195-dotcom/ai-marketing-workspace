# AI 行銷策略工作台｜學生操作說明

此網站為課堂實作工具，提供價值主張、商模、策略、客群、市場、目標、內容、會員經營、企劃報告、課堂成果及行銷實驗。

## 開始

1. 新建自己的專案，或載入「日常好食」虛擬教學範例。
2. 從工作流程、依課程、專案地圖或左側工具任選入口；可以跳著做。
3. 狀態表示有無資料及已知來源更新，不代表完成或驗證。可用狀態篩選找出待補項目。
4. 定期匯出專案JSON備份；可匯入其他裝置接續編輯。Word、PDF為成果文件，不取代JSON備份。

## 儲存與繳交

專案保存在目前裝置及瀏覽器，不會自動上傳老師端，也沒有多人共編或雲端帳號同步。換網址、清除瀏覽器資料或使用無痕模式都可能無法取回原專案，請保留JSON。繳交作業依老師指定方式提交JSON或Word／PDF。

## AI（選用）

不連AI也能手動操作。使用AI時，在「連接你的AI」選擇服務、填自己的API Key及可用文字／JSON模型；送出前查看內容，先預覽再套用。金鑰只留在本次頁面記憶體，不儲存在JSON；不要在作業或截圖公開金鑰。費用、可用模型及額度依服務帳號而定。

線上網站不會共用老師電腦的Ollama。Ollama是進階本機選項，需要操作裝置本身安裝模型，且須另確認網站來源、瀏覽器權限及連線限制；手機的localhost是手機本身。課堂可先使用老師確認的雲端服務與模型。政府補助課程的准用平台與模型以承辦單位核定為準。

## 匯出

Word為可編輯.docx。直接下載PDF為固定影像版；若需可搜尋文字可用列印另存PDF，功能依瀏覽器支援。CSV只處理彙總資料；請用UTF-8格式並依範本欄位匯入。

所有日常好食範例為虛擬教學資料，不代表真實營運、市調或成效。A/B結果僅描述差異，不自動認定顯著、勝出或因果。

## 網站發布

此資料夾為獨立靜態網站，入口index.html；GitHub Pages使用main分支根目錄，.nojekyll停用Jekyll。assets/vendor保留第三方套件授權。
